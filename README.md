# Thế giới tình yêu của Nhím và Thỏ 🌈

Level 2 ghép ảnh đã được bỏ. Hành trình: Mê cung → Memory Match + Heart Hunt → Thư tình → Chọn bài hát → Ngân hà → Kết thúc.

## Đăng lên GitHub Pages
Tải `index.html`, `script.js`, `style.css` và thư mục `assets` lên thư mục gốc của repository. Sau đó vào Settings → Pages, chọn Deploy from a branch, branch `main`, folder `/(root)`, rồi Save.
